# 评估目标

评估一条 X 帖子或 YouTube 视频对一线开发者有多少可用的实践价值。

# 评分标准

- **9-10：必看。** 一线实践者的第一手内容：可复现的做法、演示或数据，看完能直接照着用，或明显改变做事方式。
- **7-8：值得一看。** 内容具体，有工具、代码、实测或明确结论，热度也不错。
- **5-6：可以了解。** 有一定参考价值，但偏经验之谈、信息不完整或适用范围有限。
- **3-4：低优先级。** 偏观点与转述、宏观叙事或官方公告，可操作信息很少。
- **0-2：噪音。** 政策与地缘政治、融资与商业分析、标题党、纯情绪表达、广告带货、搬运内容。

# 评估要求

热度只是门槛：播放量、点赞、转发说明它被关注，但仍要看它是否包含第一手信息、可复现细节或可验证结论。个人实践者的一手内容优先于机构账号的公告与转述。宏观与政策话题即使互动量很高也要给低分。给出 3-5 个具体主题标签。
