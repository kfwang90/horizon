# X / YouTube 实践者精选

当一条内容是 X（Twitter）帖子或 YouTube 视频，作者是一线实践者，并且讲的是具体做法、工具、实测或经验时，使用此配置。

包括：

- 个人开发者、研究者、工程师与独立创作者分享的实操内容：演示、代码、基准、工具评测、工作流、踩坑记录
- 编码智能体、提示与上下文工程、RAG 与 Agent 落地的具体经验，以及可复现的效果
- YouTube 上一线开发者或研究者的教程、实测与项目讲解

不包括：

- 官方机构账号的公告与公关内容：产品发布会、企业新闻、政策表态
- 宏观、政策与地缘政治话题：监管、法案、出口管制、AGI 时间表、文明影响
- 融资、估值、股价、人事与商业分析
- 纯观点输出与情绪表达、标题党、广告与带货、搬运与转述，以及与 AI 和开发实践无关的娱乐内容
