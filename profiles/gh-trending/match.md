# AI 开发效能 / 质量工具

当一条内容是一个能直接提升软件开发效率或开发质量的 AI 工具类 GitHub 仓库时，使用此配置。目标读者是关注 AI 与软件工程实践的中文开发者。

包括（按这些方向优先）：

- 编码智能体与助手：终端、IDE、编辑器内的 AI 编码工具，代码生成、补全与重构助手
- 代码审查与质量：PR 审查、静态检查、缺陷检测、代码解释与文档生成
- 测试：用例生成、覆盖度分析、测试维护与缺陷复现
- 上下文与检索：代码库索引、仓库知识检索、MCP 服务与工具协议实现、依赖与文档供给
- 开发工作流：提交与分支辅助、CI 集成、终端与 Shell 助手，以及服务于工程交付的多智能体编排
- 提示与上下文工程：面向写代码场景的规则、技能（skills）、评测与基准工具

不包括：通用大模型训练与推理框架（除非直接服务于编码场景）、纯模型权重与数据集、与软件开发流程无关的通用 Agent 框架（炒股、舆情、爬虫编排等）、awesome 清单与导航仓库、教程与书籍合集、模板与脚手架合集、模型排行榜与论文复现、以及与 AI 无关的常规热门项目。

判断要点：这个仓库是否让开发者更快写出代码、更少引入缺陷、或更容易维护既有代码？如果答不上来，就不算符合本板块。
