# 评估目标

评估一个 GitHub 热门仓库是否值得读者今天花时间了解或试用。读者是关注 AI 与软件工程实践的中文开发者。

# 评分标准

- **9-10：强烈推荐。** 有实质技术或产品突破，已达到可实际使用的程度，能明显改变开发者的工作方式或能力边界。
- **7-8：值得一看。** 用途清晰、价值可验证：解决具体痛点，文档与代码完整，增长速度有真实需求支撑。
- **5-6：可以了解。** 有一定新意，但用途较窄、成熟度不足，或与大多数读者的日常工作关系不大。
- **3-4：低优先级。** 常规项目、重复造轮子、方向不明确，或价值主要来自宣传。
- **0-2：噪音。** 互刷 star、空壳或模板仓库、纯资源清单、与主题无关的内容。

# 评估要求

可以参考「今日新增 star」作为增长信号，但不要只看热度：star 增速快不等于质量高，也不等于有用。优先选择有真实代码、明确问题定义、可复现用法的项目。注意区分「刚发布的新项目」与「旧项目因为某个事件突然走红」。给出 3-5 个具体主题标签。
